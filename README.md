# PVRP-MP-IF Instances

Benchmark instances for the periodic vehicle routing problem with preferred pickup days, multiple service periods and intermediate facilities (PVRP-MP-IF). 
Authors: Csaba Kebelei, Balázs Dávid

The instances are adapted from the PVRP-IF waste-collection instances of Taverna and Tilk ([iolab-uniud/pvrpif-instances](https://github.com/iolab-uniud/pvrpif-instances)):

> Taverna, F., & Tilk, C. (2026). Enhancing waste collection: A branch-and-cut-and-price
> approach for the periodic vehicle routing problem with intermediate facilities applied to
> a real-world case study. *European Journal of Operational Research*, 331(2), 601–614.
> https://doi.org/10.1016/j.ejor.2025.09.039
